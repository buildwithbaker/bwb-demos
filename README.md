# bwb-demos

Four demonstration websites for fictional small businesses, built by Build with Baker from the
`bwb-templates` kit:

- `trades/` - Keweenaw Point Builders, carpentry and remodeling
- `eat-drink/` - Gitche Gumee Diner
- `stay-play/` - Superior Pines Cabins & Charters
- `shop-office/` - Chequamegon Mercantile

Live at https://buildwithbaker.github.io/bwb-demos/ (GitHub Pages, served from `main`).

The businesses, people, addresses and phone numbers are fictional, and the photos are
AI-generated. The demo forms send nothing.

When a template changes, the matching demo is rebuilt from `bwb-templates`, never
hand-patched. `CLAUDE.md` describes the demo-only layer and the branch rules.
